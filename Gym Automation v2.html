    Under the hood

    One workflow, one path in

    1

    7 triggers

    Three forms, two schedules, a backup schedule and a dashboard webhook.

    2

    Gym Config

    One node holds the gym name, sheet, owner contacts and keys.

    3

    Route by Flow

    A switch sends each run to the right flow.

    4

    Flow logic

    Code, IF and Google Sheets nodes read, check and update records.

    5

    WhatsApp Send

    One shared node, so retry rules live in a single place.

    6

    Error path

    After 3 failed tries the message is logged and the owner is emailed.

    Multi-gym

    Every gym keeps its own data

    Duplicate the workflow, edit the Gym Config node and pick that gym's credentials. Each gym gets its own Google Sheet, backup folder, dashboard key and WhatsApp number.

    Safeguards

    Built for bad days too

    Duplicate detection, three retries on every message, a failure log, an owner alert, and a weekly backup. If the AI service is down, a default message is used instead.
